READYStation LMS - Front-end Demo
=================================

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in a browser.
3. For the most reliable local preview, open the folder in VS Code and use the Live Server extension.

MAIN PAGES
- index.html - final homepage using the Index 5 hero direction and the Index 2 homepage-content structure
- courses.html - course catalog (Courses is a direct page, not a dropdown)
- hazmat-awareness.html - HazMat Awareness course information and curriculum
- hazmat-course.html - interactive course player demo
- about-us.html
- contact.html
- login.html
- register.html
- privacy-policy.html
- terms-conditions.html

CUSTOM FILES ADDED
- assets/css/readystation.css
- assets/js/readystation.js
- assets/js/course-player.js
- assets/images/logo.svg
- assets/images/logo-mark.svg
- assets/images/hero-training.svg

DEMO FEATURES
- Responsive desktop, tablet, and mobile layouts
- Fire and Rescue Academy logo and favicon
- Poppins typography with system-font fallback
- Color palette: #4B1426, #17433F, #558467, #EFEABB
- Course search and category filters
- FAQ accordion
- Scroll reveal animations
- Demo form confirmations
- Interactive HazMat quizzes
- Drag-and-drop recognition activity
- Click-to-match activities
- Lesson completion and progress saved in the browser via localStorage
- Mobile course-outline drawer

IMPORTANT DEMO NOTES
- Login and registration are intentionally not connected to a backend.
- Contact and account forms show demo confirmations only.
- Course completion is stored only in the current browser.
- The HazMat course does not issue certification and does not replace agency-approved instruction, practical evaluation, local procedures, or regulatory requirements.
